# Alfa66 Bau GmbH – Website Redesign 2026

This branch contains the new editable source project for the Alfa66 website.

## Positioning

Primary audience: larger construction partners, industrial/commercial clients, and contractors needing reliable Tiefbau teams and operators.

Secondary audience: smaller projects such as driveways, parking areas, courtyards, sidewalks and paving jobs.

## Core messaging

Alfa66 sells services and experienced personnel, not machinery rental.

Main services:
- Tiefbau
- Erdarbeiten
- Kabeltiefbau
- Rohrleitungsbau
- Pflaster- & Oberflächenarbeiten
- Industrie- & Gewerbetiefbau

## Technology

- Next.js 16.3.8
- React 19.2
- Static export enabled
- Production build is generated into the out folder

## Commands

    npm install
    npm run dev
    npm run build

Upload the generated out folder contents to the web server.
